# Portfólio profissional — Mylena dos Santos Rocha

Site pessoal que apresenta minha trajetória em Administração, Planejamento, Processos, Automação, Análise de Dados e Tecnologia da Informação.

## Acessar o portfólio

https://mylena-santosr.github.io/

## Estrutura do projeto

- `index.html`: conteúdo, seções e links do portfólio.
- `style.css`: identidade visual, componentes e responsividade.
- `script.js`: botão de voltar ao topo, atualização do ano e destaque do menu.
- `imagens/Avatar_Mylena.png`: ilustração de perfil utilizada no site.

## Tecnologias utilizadas

HTML5, CSS3 e JavaScript. O site é estático e não precisa de instalação de dependências, framework ou processo de compilação.

## Executar localmente

Abra `index.html` em um navegador ou, na pasta do projeto, execute:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000/`.

## Publicar no GitHub Pages

1. Faça uma cópia de segurança dos arquivos atuais.
2. Substitua `index.html`, `style.css`, `script.js` e `README.md` pelos arquivos atualizados. Mantenha a pasta `imagens`.
3. Confirme as alterações na branch configurada para publicação no GitHub Pages (normalmente `main`).
4. Em **Settings > Pages**, confira se a publicação usa a branch correta e a pasta `/ (root)`.
5. Acesse o site publicado e verifique os links.

## Manutenção

- Para alterar textos e projetos, edite o `index.html`.
- Para ajustar cores e aparência, edite as variáveis CSS no início de `style.css`.
- Para trocar o avatar, substitua `imagens/Avatar_Mylena.png` mantendo o nome ou ajuste o caminho no HTML.
- O botão **Solicitar currículo** abre um e-mail. Nenhum PDF de currículo é publicado automaticamente, para evitar divulgar uma versão desatualizada ou dados pessoais sem revisão.
- O botão **Enviar e-mail** abre o aplicativo de e-mail do visitante, sem formulário próprio ou coleta de dados no site.

## Observações

O conteúdo diferencia experiências profissionais e projetos acadêmicos ou pessoais. Não publique códigos, dados ou documentos internos de empregadores sem autorização.
